game and how to receive free OUACC coaching. For information about

## Learning the game

[<img src="../images/lawn.gif" alt="Simplified croquet court layout" data-hspace="15" data-vspace="0" style="float: right; margin: 0 0 15px 20px;" />](https://www.oxfordcroquet.com/coach/simplified/)

To find information on the web about learning the game and tactics of
croquet OUACC recommends the website the book "Know the Game Croquet".
This should be available in all good college libraries! For beginners we
recommend looking at the
<a href="http://www.oxfordcroquet.com/coach/simplified/"
target="_top"><strong>simplified laws</strong></a> article on Dr Ian
Plummer's
<a href="http://www.oxfordcroquet.com" target="_blank">Oxford Croquet
website</a> . This website houses a huge number of articles wherein you
can find out just about anything you want to know regarding croquet. We
strongly recommend checking out the
<a href="http://www.oxfordcroquet.com/coach/index.asp"
target="_top">coaching section</a> for those eager to improve their
tactics.

The Croquet England site also has
<a href="https://www.croquetengland.org.uk/play-association-croquet/"
target="_blank">a basic set of laws</a> and a full set of laws. The full
laws are intricate and it is difficult to get the gist of the game from
them alone. However, they will resolve almost all disputes!
